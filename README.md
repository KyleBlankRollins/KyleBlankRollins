## Hi, I'm Kyle 👋

Engineering manager, technical writer, and developer. At MongoDB I lead Agent Research
and Tooling, a team that runs practical AI agent experiments, builds the tools to analyze
them, and works on the tooling behind
[MongoDB's official agent skills](https://github.com/mongodb/agent-skills).

I came up through docs-as-code: documentation that's versioned, tested, reviewed, and
built with the same tools as the software it describes.
